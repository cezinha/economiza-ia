1. Resumo Executivo

O Economiza+ MVP é um sistema de análise financeira e recomendações personalizadas desenvolvido para auxiliar famílias brasileiras das classes C e D a melhorar sua saúde financeira. O projeto utiliza técnicas de machine learning para segmentar usuários em perfis financeiros distintos e gerar recomendações de economia específicas para cada perfil.

2. Introdução

2.1 Contexto

O Brasil enfrenta uma crise financeira crônica que afeta milhões de famílias:

IndicadorValorFonte
Inadimplentes80,6 milhõesSerasa, 2024
Famílias endividadas79,5%CNC, 2024
Não conseguem poupar60%IBGE, 2023
Dívida médiaR$ 4.042Serasa, 2024

2.2 Problema

As soluções existentes de gestão financeira são geralmente genéricas, complexas e inacessíveis para as classes C e D.

2.3 Proposta

O Economiza+ propõe um sistema que analisa automaticamente o comportamento financeiro, segmenta usuários em perfis distintos, personaliza recomendações e monitora transações suspeitas.

9. Discussão e Limitações

9.1 Pontos Fortes

  • Abordagem personalizada por perfil
  • Clusters interpretáveis para usuários finais
  • Pipeline escalável (~20 usuários/segundo)
  • Documentação completa (13 notebooks)
  • Interface amigável com Streamlit

9.2 Limitações

  • Dataset sintético não captura correlações reais
  • Silhouette Score abaixo do ideal
  • Cluster 1 requer abordagem diferente (educação financeira)
  • Sem validação com usuários reais

9.3 Lições Aprendidas

LiçãoDescrição

10. Conclusão

O projeto Economiza+ MVP atingiu seus principais objetivos, demonstrando a viabilidade de um sistema de recomendação financeira personalizada para as classes C e D. A economia projetada de R$ 2,26 milhões/ano para 500 usuários indica potencial significativo de impacto social.
